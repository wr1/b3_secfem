## Same problem vs ANBA

Stage-1 `ε_zz` (Fz, Mx, My). Top row secfem, bottom row ANBA. Fz mean matches to machine precision; Mx `ε_zz` RMS is the same **1.1 %** as the stress field (homogeneous iso, so `σ = C ε` is a uniform scale).

<img src="/figures/recovery/iso_strain_compare.png" alt="secfem vs ANBA Stage-1 epsilon_zz" />

Poisson check under Fz: a free isotropic section contracts `ε_xx = ε_yy = −ν ε_zz`. Both codes recover that field (`ε_xx / ε_zz = −0.30`).
