title: Transform

This is step 3 of [three](/docs/conventions/walkthrough). It is the only map from [material](/docs/conventions/material-card) into [section](/docs/conventions/section-frame).

```
R(β, α) = Rz(β) · Ry(α)
```

`v_section = R · v_mat`. A material vector sees **`α` about global `y`, then `β` about global `z`**. `(0, 0)` is the identity — the same zero as ANBA `(fiber, plane) = (0, 0)`.

The two angles **do not commute**. `Rz(β)·Ry(α)` equals `Ry(α)·Rz(β)` only when `β = 0` or `α = 0`.

## Default `(β, α) = (0, 0)`

<img src="/figures/place_a0.png" alt="(0,0): fibre along +x, mat_2 along +y, mat_3 along +z" />

| axis | lands on |
|------|----------|
| `mat_1` fibre | `+sec_1` (`+x`) |
| `mat_2` in-ply | `+sec_2` (`+y`) |
| `mat_3` ply-normal | `+sec_3` (`+z`) |

## `β` at `α = 0`

`β` is a right-hand rotation about `+sec_3`. The fibre stays in the section plane. `β = 0` is fibre along `+x`; `β = 90` is fibre along `+y`.

<img src="/figures/place_beta_alpha0.png" alt="beta sweep at alpha 0" />

## Other pins

| `(β, α)` | what |
|----------|------|
| `(0, 90)` | fibre along `−z` (beam); `mat_2` along `+y`; `mat_3` along `+x`. Same `T` as ANBA `(fiber, plane) = (90, 0)`. |
| `(90, 0)` | fibre along `+y`; `mat_2` along `−x`; `mat_3` along `+z` |

## `β` at `α = 90` and `α = 45`

At `α = 90` the fibre stays on `−z`; `β` rolls 2/3 in the section.
