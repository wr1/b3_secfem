That is the same split as [Why they still differ](/docs/theory/residuals): the transform is closed; Fy and mid-tilt are formulation.

Mid-tilt (`α = 45`) is the orange/red row. ANBA 9–12 % on Fz/Mx/My; gxbeam 28–38 % on those. Do not edit `R`.

gxbeam has no `β`. On a rectangle that only needs `α`, fibre-on-beam UD matches secfem tightly. The 2↔3 bridge is only for gxbeam’s in-plane endpoint (E2 on `z` vs secfem E3 on `z`).

## NACA 0018 station

Hollow 0018, chord 1 m, glass-biax skin, carbon-UD spar caps, one biax web at 35 % chord. 136 quads. Ply 0° = spanwise → secfem `α = 90`, ANBA `fiber = 90`, gxbeam `θ = π/2`; `β` = shell tangent (secfem and ANBA only).

**gxbeam** after the CCW fix: axial, Mx, Fy, and both centres sit on secfem. My / Fx / Mz do not — gxbeam never sees the skin `β` (tangent roll of the biax). That is a missing input, not a 2/3 rewrite.

**ANBA** on this multi-region foil returned a **negative** `K[Fz,Fz]` even though every split triangle is CCW (272/272). `|EA|` is close (1.63 vs 1.67 e9) but the matrix is not positive definite. Treat that as a failed ANBA run on this mesh, not as a convention residual. The ladder (single-material) ANBA runs are the ones that close Stage 1.

## How to read a new case

1. Map inputs ([adapters](/docs/solvers/adapters)). Same card.
2. Flip CW quads before ANBA/gxbeam.
3. Compare `K` in `[Fx, Fy, Fz, Mx, My, Mz]`.
4. If Fz/Mx/My match and Fy does not, that is [Stage 2](/docs/theory/residuals).
5. If Fz comes out negative, stop — do not interpret the rest as material-frame error.
